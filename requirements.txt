# Lower bounds rather than exact pins, so pip installs the newest wheel for
# whatever interpreter you are on. Exact pins are what caused pydantic-core to
# try to compile from source on Python 3.14 — there was no cp314 wheel for the
# pinned version, so pip fell back to building it with Rust.
#
# Two dependencies were deliberately removed:
#   passlib      — imports the stdlib `crypt` module, deleted in Python 3.13.
#                  bcrypt is used directly instead; it is what passlib called.
#   python-jose  — effectively unmaintained and drags in ecdsa + rsa.
#                  PyJWT does the same job and is actively released.
